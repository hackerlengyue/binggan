# 安全与隐私

[README](../README.md) · [English](#english)

## 分享问题报告

报告中应包含软件版本、操作系统、复现步骤和报错。公开 Issue、PR 或截图前，请删除真实密钥、采集请求正文、登录信息、证书私钥、签名凭据和个人文件路径。

采集内容和日志可能包含敏感信息。只分享复现问题所需的部分；诊断问题不需要上传整个工作区或用户数据库。

## 报告安全问题

如果仓库启用了 GitHub 私密漏洞报告，请使用该入口。未启用时，先与维护者确定私密沟通方式。公开报告可描述问题类型，避免附上凭据或可直接利用的敏感细节。

## English

[README](README.en.md)

### Share a bug report

Include the application version, OS, reproduction steps, and error. Remove real keys, captured request bodies, login details, private certificates, signing credentials, and personal paths from public issues, pull requests, and screenshots.

Captured content and logs may contain sensitive information. Share only what is needed to reproduce the issue. Diagnostics do not require uploading an entire workspace or user database.

### Report a security issue

Use GitHub private vulnerability reporting if it is enabled. Otherwise, arrange a private channel with the maintainer. A public report can describe the issue category without credentials or sensitive exploitation details.
