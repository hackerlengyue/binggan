# Binggan v2.0.1

本次更新增加密钥 JSON 导入，适配 SzPlayer `26.10.56` 的密钥处理和播放编排，并修复连续课程之间重建分流连接引起的中断。

## 更新内容

- **密钥导入**：密钥管理和视频解密入口支持上传密钥 JSON；批量导入会校验文件格式、大小和解密参数，保留原有槽号、重复密钥及播放器参数。
- **SzPlayer 26.10.56 兼容**：增加版本校验值，修正模式 `1` 的固定槽位、模式 `3` 的偏移计算和舍入方式，支持 `<null>` 模式及显式导入 `mimatuokeqian` 的模式 `4`。
- **采集与历史记录**：成对保存每次主密码请求的 `uit` 和响应密文，按实际槽位保存密钥，拒绝错误响应和播放器占位密钥。保留旧版采集兼容；新版历史只有在原始请求完整覆盖已存密钥时才恢复槽位。
- **播放编排**：统一播放器版本配置，保留 `26.06.54` 支持，并适配 `26.10.56` 的播放按钮位置。未知版本继续阻止自动操作。
- **连续课程分流**：整个执行队列复用同一个原生分流连接，课间仅切换记录接收，每节课程仍单独保存。任务结束、页面关闭或重载时释放连接并恢复分流。
- **Surge 查询恢复**：只读查询遇到短暂失败时，在原有时限内最多尝试 3 次；配置修改不重复执行。错误信息省略可能含凭据的命令参数和原始诊断输出。
- **依赖与构建**：MyGo CLI、运行时和 Go 模块统一升级至 `0.8.3`，Go 升级至 `1.27.3`。移除旧版 MyGo 构建补丁，macOS 显式启用辅助功能驱动所需的 cgo。

- **Windows ARM64 构建**：修复上游 FFmpeg 自动构建资源删除造成的下载失败，改用此前正式发布包中校验值相同的工具和许可证，保留原有二进制校验值。

## 验证与限制

发布前已通过 `npm run check`：绑定生成、全部 Go 测试、360 项前端测试、类型检查、前端生产构建、结构检查及仓库检查。版本配置和锁文件均为 `2.0.1`。

四种解密模式已使用合成 MP4 验证，不能替代新版真实 `.sz` 样本及完整会话验证。缺少原始请求的压缩编号 JSON 无法可靠恢复槽位，需要重新采集。新版 PCM 音频变换、登录后的完整课程队列和系统授权等实机行为仍需验证；本次未新增 PDF 解密功能。详细范围见 [兼容性记录](https://github.com/hackerlengyue/binggan/blob/v2.0.1/docs/development/szplayer-26.10.56.md)。

源码提交前已执行隐私检查。发布包由 GitHub Actions 的干净检出环境构建；本地数据库、采集记录、导入密钥、证书、日志和个人配置不纳入提交或发布附件。

## English

- Import key JSON files from key management and video decryption, with validation and preservation of slot numbers and player metadata.
- Add SzPlayer `26.10.56` key handling and playback profiles while retaining supported older versions. Correct fixed and offset slot selection; support `<null>` and explicitly supplied mode `4` keys.
- Keep request-specific `uit` values paired with their encrypted responses, reject failed responses and placeholder keys, and recover historical slots only when complete original traffic is available.
- Retain one native routing session across the queue, save separate lesson records, and restore routing when execution ends or the page closes or reloads.
- Retry transient read-only Surge queries without repeating configuration changes or exposing sensitive diagnostics.
- Upgrade MyGo to `0.8.3` and Go to `1.27.3`, simplify build scripts, and retain cgo for the macOS Accessibility driver.

Validation includes all Go tests, 360 frontend tests, type checking, production frontend build, generated bindings, and repository checks. New-player decryption uses synthetic fixtures; real `.sz` sessions, PCM audio transforms, full logged-in playback queues, and system permission flows still need validation. Windows runtime is untested and its native playback driver is not implemented. Release archives are built from a clean GitHub Actions checkout and exclude local user data.

The Windows ARM64 resource manifest now extracts the same checksum-pinned tools and license from the existing v2.0.0 release archive after the original upstream autobuild was removed.
